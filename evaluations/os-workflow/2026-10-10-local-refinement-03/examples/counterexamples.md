# Contraejemplos del autor

1. «Redactar el informe y definir criterios después»: no entrega contenido específico del output futuro ni criterios revisables.
2. «Output: el propio borrador»: no identifica qué producirá el trabajo futuro.
3. «Criterio: alcanzar WAPE<10% aprobado» sin evidencia: inventa un acuerdo; un threshold propuesto debe identificarse como tal.
4. READY antes de ##Estado o ausencia de ese H2: incumple el contrato que exige estado dentro de la sección.
5. NOT_DETERMINABLE solo porque falta acceso para un trabajo posterior, cuando el encargo actual permite preparar seguimiento: confunde las acciones.
6. READY para ejecutar una consulta prohibida: la preparación autorizada no concede permisos posteriores.

Estos ejemplos y revisiones pertenecen al autor; no son resultados de agente ni casos inéditos para una futura evaluación.
