# Contexto de negocio

Engagement independiente simulado para anticipar carga semanal de preparación de un comercio online. Datos históricos reales UCI Online Retail II; no hay un cliente contratante ni usuarios operativos observados.

Decisión: proponer un forecast de facturas positivas registradas por semana como proxy de volumen. Owner operativo y uso son simulados; David revisa el paquete. Sin tiempos por factura ni disponibilidad de personal, no se calcula staffing óptimo, SLA, ahorro o ROI.

El ensayo empieza en validation para probar conjuntamente las pautas nuevas con un método acotado. Se prepararon contexto y contratos como evidencia de entrada; no se declaran etapas anteriores aprobadas.
